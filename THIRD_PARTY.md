# Dependencies and data

LUCENT uses NumPy, SciPy and threadpoolctl, installed separately under their respective licenses. The interactive report uses bundled LUCENT HTML, CSS and JavaScript and runs without a hosted service.

The example generates synthetic measurements and identifiers. No third-party GWAS, spatial transcriptomics, gene annotation or ligand–receptor catalogue files are distributed in this code repository. Users supply their research inputs and retain their source attribution and terms.
